# Programming Together: Student Lessons

A hands-on introduction to programming in **C**, followed later by **modern C++**. This is an informal course: build things, experiment, change the code, and have fun.

## How to use these lessons

Keep this page open in a browser on one monitor and Visual Studio on the other. Type, run, and change the sample programs. Every exercise is an invitation to experiment; there are no quizzes or grades.

Save your own projects in a folder on your PC. The example files in this repository are for reference, not your personal working copies.

## Reference

This course draws inspiration from [Harvard CS50x](https://cs50.harvard.edu/x/2026/) but uses original, shorter activities designed for our sessions. You do not need to watch its lectures to participate.
